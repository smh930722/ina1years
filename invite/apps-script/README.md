# 방명록·참석 여부 저장 연결하기 (10분, 한 번만)

1. Google 드라이브에서 새 스프레드시트를 만든다. 이름 예: `이나 돌잔치 응답`
2. 메뉴 **확장 프로그램 → Apps Script**를 연다.
3. 기본 코드를 지우고 `Code.gs` 내용을 통째로 붙여 넣은 뒤 저장한다.
4. 오른쪽 위 **배포 → 새 배포**
   - 유형: **웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. 권한 승인 창이 뜨면 본인 계정으로 승인한다. ("확인되지 않은 앱" 경고가 나오면 고급 → 이동)
6. 배포가 끝나면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사한다.
7. `invite/config.js`의 `apiUrl: ''` 따옴표 안에 붙여 넣는다.

## 응답 보기
- `방명록` 시트: 남긴 축하 메시지. 지우고 싶은 글은 `숨김` 칸에 아무 글자나 적으면 초대장에서 사라진다.
- `참석` 시트: 이름, 참석 여부, 인원, 메모.

## 코드를 고쳤을 때
배포 → 배포 관리 → 연필 아이콘 → 버전 '새 버전' → 배포. (URL은 그대로 유지된다)
